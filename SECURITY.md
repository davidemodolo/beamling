# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, never in a public issue or pull request:

- **GitHub:** [Report a vulnerability](https://github.com/davidemodolo/beamling/security/advisories/new) (private vulnerability reporting), or
- **Email:** the address in [security.txt](https://beamling.app/.well-known/security.txt), also on the [contact page](https://beamling.app/contact).

Include the affected URL or file, reproduction steps and the impact. Reports are acknowledged within two working days. You will be kept informed while the issue is fixed and credited when the fix is published, if you wish.

## Scope

- The hosted service at https://beamling.app.
- The code in this repository, including the deployment scripts under `deploy/`.

Only the latest release is supported; fixes ship as a new release.

## Safe harbour

No legal action will be taken over research done in good faith that follows these rules:

- Use only your own account, keys and data.
- Do not access, change or keep other users' data.
- Do not degrade the service, send spam, or run denial-of-service or social-engineering tests.
- Give reasonable time to fix the issue before disclosing it.

The full policy is at https://beamling.app/security.
